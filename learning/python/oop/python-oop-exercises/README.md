# Practical Python OOP Exercises

## Objective

Build confidence with the core object-oriented programming (OOP) ideas in Python by writing, running, and changing small programs. The collection moves from individual objects to collaborating classes and method resolution.

## Prerequisites

- Python 3.10 or later.
- Basic Python syntax: variables, functions, conditionals, loops, lists, and exceptions.
- A terminal and a text editor.

No external packages are required.

## Organization

Each file in `exercises/` contains four progressive exercises for one OOP topic. Matching runnable templates live in `starter_code/`; matching reference implementations live in `solutions/`.

Exercise numbers are global: exercise 01 uses `starter_code/exercise_01.py` and `solutions/exercise_01_solution.py`, and so on through exercise 32.

## Running Python files

From this directory, run a starter or a solution with:

```bash
python3 starter_code/exercise_01.py
python3 solutions/exercise_01_solution.py
```

On Windows, replace `python3` with `python` if needed.

## Recommended study workflow

1. Read one exercise in order.
2. Open its matching starter file and implement the requested behavior.
3. Run the file frequently from the terminal.
4. Compare its behavior with the expected output in the exercise.
5. Only after making a serious attempt, inspect the matching solution and explain every line to yourself.
6. Change one requirement or add one small test to consolidate the idea.

## Progress checklist

- [ ] 01–04: Classes, objects and state
- [ ] 05–08: Methods, commands and queries
- [ ] 09–12: Encapsulation
- [ ] 13–16: Inheritance
- [ ] 17–20: Method overriding
- [ ] 21–24: Polymorphism and duck typing
- [ ] 25–28: MRO and `super()`
- [ ] 29–32: Mixed OOP challenges

> Warning: do not inspect `solutions/` before attempting an exercise. The useful learning happens while you make predictions, run code, and fix your own mistakes.
